## 문제 핵심
- 정수 N을 1로 만들기 위해 허용된 연산을 최소 횟수로 사용하는 문제
- 각 수에 대해 최적의 이전 상태를 선택하는 DP 문제

---

## 떠올려야 하는 관찰(사고 포인트)
- 현재 수 i의 최적 해는 i보다 작은 값들의 최적 해를 기반으로 결정된다
- 가능한 연산은 최대 3가지로 고정되어 있다
- 모든 값을 1부터 차례대로 계산하면 중복 계산을 피할 수 있다

---

## 핵심 아이디어 / 기술
- Bottom-up 동적 계획법 (DP)
- dp[i] = min(dp[i-1], dp[i//2], dp[i//3]) + 1
- 나눗셈 연산은 조건을 만족할 때만 고려

---

## 실수 포인트 / 헷갈리는 부분
- N이 작은 경우를 별도로 처리하지 않으면 인덱스 오류 가능
- 매 반복마다 불필요한 연산(리스트 생성 등)은 시간 초과 위험
- 시간 제한이 매우 짧아 구현 효율이 중요

---

## 시간복잡도 / 왜 통과되는지
- 각 i에 대해 상수 번 연산만 수행
- 전체 시간복잡도 O(N)
- N ≤ 1,000,000 범위에서 파이썬으로도 충분히 통과
